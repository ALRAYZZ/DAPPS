DAPPS 
Your daily Apps App.
One app to launch them all.

Its small desktop application, build using new WinUI3 framework for the front end. The application basically is a library, that requires the user to locate the .exe of the programs the want to add to the library, and then user can also choose an icon for the "card" style display that we use, and from there the application converts each app that the user adds, to a card, and tracking the processes that are running in the machine can tell and shows with a red border if the app is running.

From the app main window, will display all cards/apps added and you can launch those apps from there and also close them if DAPPS detects they are running. 

Also there is a second window for each card/app, where user can change the name and icon of the card/app.
